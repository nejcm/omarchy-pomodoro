# Glossary

- *session*: a timed interval once started, whatever its phase; it can be
  running, paused, or finished.
- *pomodoro*: a completed work interval. It is what the history logs and the
  cycle counts.
- *phase*: the kind of interval, either work, short break, or long break.
- *cycle*: the configured number of pomodoros leading to a long break.
- *armed*: selected as the next phase and duration, but not running.
- *idle*: no session has been started; the next one is armed.
- *mode*: the selected behaviour. Timer runs one work countdown; Pomodoro
  runs the work/break cycle.
